# Stress-test checklist

Score each as **Pass / Caution / Fail**, with one line of reasoning. Use ranges when the user gives approximate numbers.

## 1. Concentration
- Position as % of investable assets: under 5% low, 5-15% moderate, over 15% high, over 25% very high. (Rules of thumb for discussion, not rules.)
- Position as % of net worth, including home and business.
- **Hidden correlation**: does it move with the user's job, employer, sector, local property or other holdings? (Example: an engineer at a tech firm buying tech stock.)
- Number of positions that would fall together in the same scenario.

## 2. Liquidity
- Time to convert to cash, and the likely cost (spread, exit load, penalty, tax).
- Gates, lock-ins, redemption limits, minimum holding periods.
- Does the user have an **emergency fund separate from this money** (3-6 months of expenses is a common guideline)?

## 3. Hold-through test
Ask these directly and record the answers:
1. If this is down 40%, do you need this money in the next 3 years?
2. Could you keep paying all obligations without selling it?
3. Have you lived through a 30%+ drop in something you owned? What did you do, and what did you feel?
4. Would you check the price daily? Would a 40% drop change how you sleep or behave?
5. Is anyone else relying on this money (family, a goal with a date)?

**Fail** if a "yes" to Q1 or "no" to Q2. **Caution** if Q3 shows a past panic-sell.

## 4. Leverage and obligations
- Any borrowed money, margin, EMIs, or credit used?
- Leverage plus illiquidity is the combination that forces bad exits.

## 5. Size that would pass
If any check fails, compute (don't prescribe) the position size at which concentration and hold-through checks would pass, so the user can see the trade-off. Present as "at X, these checks pass", not "you should buy X".
